# HR Management

Dự án giao diện quản lý nhân sự bằng HTML, CSS và JavaScript thuần.

## Chức năng

- Tổng quan
- Quản lý nhân viên
- Quản lý phòng ban
- Quản lý tài khoản
- Quản lý thanh toán
- Quản lý đơn từ
- Quản lý chấm công

## Chạy dự án

Mở `index.html` trực tiếp trong trình duyệt hoặc chạy dự án bằng Live Server trong VS Code.
